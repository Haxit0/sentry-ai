# Sentry AI submission description

**Track:** The Agent That Can Explain Why

Sentry helps supply-chain operations managers investigate delayed suppliers, compare recovery
choices and understand what would change a recommendation. Zetaris federates orders, supplier
offers, inventory and carrier updates. Nightshift-powered agents investigate and challenge the
evidence. Exact financial checks block unsupported claims, and Meterless H-MEM recalls validated
findings for subsequent investigations. Human reviewers receive a portable decision packet.

The output shows why other options lose, whether they meet spending and lateness limits, and the
next delay at which the ranking changes. Conflicting arrival reports produce an explicit range
and a request for confirmation. Evidence gaps return to the Planner. Historical memory guides
the inquiry without overriding current calculations.

The synthetic Alpha five-day case produces GBP 500.00 exposure and GBP 160.00 expedited recovery,
a hypothetical GBP 340.00 saving. At seven days, alternative sourcing becomes cheaper. These are
reproducible scenario results, not measured customer savings. The data is small and synthetic,
although source queries and model inference are real.

## Pre-existing components and tool disclosure

The calculator, agent/data feature branches and dashboard baseline existed before this integration
session, as recorded in Git. New work combines those contributions and adds versioned live flows,
constraints/counterfactuals, a Critic and feedback, durable runs, human reviews and exports.
FastAPI, Pydantic, React, Vite, Playwright, Qwen, Nightshift, PostgreSQL and Docker are third-party
components. The H-MEM reference is vendored unmodified, version-pinned and Apache-2.0 licensed.

This integration used OpenAI Codex and VS Code. Do not claim Cursor use unless a contributor confirms
it. NVIDIA CUDA accelerates local Qwen inference on an RTX 4080 Laptop GPU; no Nemotron claim is made.
